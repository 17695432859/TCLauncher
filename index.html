它是什么

一次彻底重写，
从界面到核心

TCraft Launcher 的定位很直接：轻一点，快一点。 它是一个免费开源的《我的世界》Java 版启动器，作者 DamianJiang。 v1.0.0 之前，它用 VB.NET / WPF 写过一版；这一次是用 JavaFX 从头重写， 架构、界面、交互全部换新。

它没有安装向导、没有捆绑、也不做统计上报——资源与 JavaFX 运行库都内嵌进那个 exe， 首次运行时自动解压到用户目录 ~/.tcraft-launcher-javafx/。 拷到哪儿都能跑，删掉文件夹就算卸载干净。

界面上最显眼的是毛玻璃卡片压在背景图上，主题色从壁纸里自动提取， 另有 30 种预设色板可换。组件透明度和动画速度也能调。

编译

想自己动手？
两条命令就够

仓库里直接带了各平台的 JavaFX 运行库，不需要额外配依赖。JDK 17 以上，克隆下来就能编。

bash — build & run 
# 编译（需要 JDK 17+）
javac --module-path lib --add-modules javafx.controls,javafx.graphics,javafx.base,javafx.media \
      -encoding UTF-8 -d out src/tcraft/*.java

# 运行
java --module-path lib --add-modules javafx.controls,javafx.graphics,javafx.base,javafx.media \
     -cp out tcraft.Boot

仓库结构：src/tcraft/ 源码 · res/ 图标语言表样式 · lib/ JavaFX 运行库 · tools/ 原生启动器（launcher.c）· website/ 官网

常见问题

你可能想知道的

TCraft Launcher 和 HMCL、PCL2 是什么关系？
没有隶属关系。作者在 README 里明确说明：功能规划与交互设计参考了 HMCL 的成熟方案，但界面与代码全部独立编写，与 HMCL、PCL 均无隶属、赞助或背书关系。
为什么装了却打不开？
大概率是缺 Java。启动器自带 JavaFX 但不带 JRE，需要系统里已有 Java 17 或更高版本。单文件版检测不到 Java 时会给出下载指引，照着装一个即可。
「单文件」是什么意思？会不会偷偷装东西？
资源与 JavaFX 运行库都内嵌在那个 exe 里，首次运行时解压到 ~/.tcraft-launcher-javafx/，没有安装向导、没有捆绑软件、也不做统计上报。删掉那个目录就等于卸载干净。
联机需要公网 IP 或端口映射吗？
不需要。联机房间基于 EasyTier 虚拟局域网：房主在游戏里「对局域网开放」，然后把邀请码发给朋友，对方加入房间就能直连。首次使用会按平台自动下载 EasyTier，Windows 需要管理员权限，macOS 按弹窗授权，Linux 建议 sudo。
支持正版登录吗？离线能用吗？
都支持。微软账号一键登录，浏览器里登完会自动跳回启动器，不用手动复制链接；同时也支持离线登录和外置 Authlib 认证（如 LittleSkin）。
可以商用或者二次分发吗？
项目采用 MIT License，比较宽松，允许修改与再分发，保留版权声明即可。另外它引用了 Lucide 图标（ISC）与 EasyTier，Minecraft 是 Mojang / Microsoft 的商标，本项目与其无关。
